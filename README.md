# 게시판 프로젝트

게시글 CRUD 및 회원 인증 기능을 제공하는 웹 애플리케이션입니다.

## 배포 링크
https://task-henna-delta.vercel.app/

## 실행 환경

- Node.js 18.18 이상

## 실행 방법

```bash
# 1. 의존성 설치
npm install

# 2. 개발 서버 실행
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000) 접속

## 주요 기능

- 회원가입 / 로그인
- 게시글 목록 조회 (페이지네이션)
- 게시글 작성 / 상세 조회 / 수정 / 삭제

## 기술 스택

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS / Sass
- React Hook Form + Zod
